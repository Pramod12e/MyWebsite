I built this site to learn a modern web stack by doing, not just watching tutorials.

## The stack

- **Next.js** for pages and routing
- **TypeScript** for safer code
- **Tailwind CSS** for styling
- **MDX** for writing posts like this one

## A small TypeScript example

```ts
type Project = {
  title: string;
  tags: string[];
};

const site: Project = {
  title: "My Portfolio",
  tags: ["Next.js", "Tailwind"],
};

console.log(site.title);
```
